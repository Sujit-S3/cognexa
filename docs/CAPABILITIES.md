# Cognexa v1.0 Capability Matrix

This matrix is the source of truth for the `web/` and `Server/src/` release-candidate surface. The frozen `Client/` and legacy JavaScript server are migration references, not deployable capabilities.

| Domain         | Supported in the release candidate                                                                                                                                    | Not supported                                                                             |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Identity       | Registration, login, password recovery/reset, short-lived access tokens, rotating hashed refresh sessions, session listing/revocation, RBAC                           | Email-verification delivery workflow, SSO, SCIM, organization tenancy                     |
| Catalog        | Public published-course list/detail, authenticated enrollment and un-enrollment                                                                                       | Commerce, entitlements, ratings/reviews, search service                                   |
| Instructor     | Persisted drafts, optimistic autosave, setup/SEO, signed Cloudinary media, curriculum and assessment authoring, review/publish/archive lifecycle, dashboard summaries | Cohort communication, durable jobs, revenue/commerce                                      |
| Learner        | Real enrollment and legacy assessment-deadline summaries                                                                                                              | Playback, progress persistence, notes, certificates                                       |
| Assessments    | Instructor quiz/assignment authoring embedded in course drafts; legacy deadline reads                                                                                 | Learner delivery, durable submissions, grading, receipts, appeals                         |
| AI             | Authenticated, rate-limited, bounded server gateway; HTML-safe browser rendering; real gateway required when enabled in staging/production                            | Course-aware retrieval, safety event store, evaluations, cost governance                  |
| Community      | Authenticated lecture-comment API with bounded comment input and ownership deletion                                                                                   | Discussion/community UI, moderation, announcements, social graph                          |
| Administration | Global admin role can access instructor-owned operations                                                                                                              | User/governance console, audit-event console, delegated administration                    |
| Notifications  | Password-recovery email when SMTP is configured                                                                                                                       | General notification center, push, preferences, delivery tracking                         |
| Operations     | Health/readiness/dependency probes, protected metrics, structured logs, optional traces, migrations, backups, Kubernetes, release/deploy/rollback workflows           | Verified cloud deployment, provider configuration, queue workers, tested restore/failover |

Historical demo-only learner, assessment, notification, certificate, and admin components were removed. Their public route shapes are retained where applicable and render an explicit unavailable state, preserving bookmarks without pretending that data was persisted.
