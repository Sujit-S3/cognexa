# Cognexa v1.0 Capability Matrix

This matrix is the source of truth for the `web/` and `Server/src/` release-candidate surface. The frozen `Client/` and legacy JavaScript server are migration references, not deployable capabilities.

| Domain         | Supported in the release candidate                                                                                                                                                                                                                                  | Not supported                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Identity       | Registration, login, password recovery/reset, short-lived access tokens, rotating hashed refresh sessions, session listing/revocation, RBAC                                                                                                                         | Email-verification delivery workflow, SSO, SCIM                                           |
| Catalog        | Public published-course list/detail, authenticated enrollment and un-enrollment                                                                                                                                                                                     | Commerce, entitlements, ratings/reviews, search service                                   |
| Instructor     | Persisted drafts, optimistic autosave, setup/SEO, signed Cloudinary media, curriculum and assessment authoring, review/publish/archive lifecycle, dashboard summaries, assignment grading queue with rubric scoring                                                 | Cohort communication, durable jobs, revenue/commerce                                      |
| Learner        | Real enrollment, curriculum playback for every lesson type, server-computed progress with resume, quiz taking with instant auto-grading and post-grading answer-key/explanation reveal, assignment submission with file attachments, automatic certificate issuance | Notes, live-session hosting, offline access, proctoring                                   |
| Assessments    | Instructor quiz/assignment authoring embedded in course drafts; learner attempt delivery with question-pool sampling and randomization; durable submissions; synchronous quiz auto-grading; manual rubric-based grading                                             | Appeals workflow, AI-assisted grading, code-execution sandbox                             |
| Certificates   | Automatic, idempotent issuance on course completion (all required lessons plus every published assessment passed); on-demand PDF; public verification by code                                                                                                       | Custom/branded certificate templates, revocation workflow                                 |
| AI             | Authenticated, rate-limited, bounded server gateway; HTML-safe browser rendering; real gateway required when enabled in staging/production                                                                                                                          | Course-aware retrieval, safety event store, evaluations, cost governance                  |
| Community      | Authenticated lecture-comment API with bounded comment input and ownership deletion                                                                                                                                                                                 | Discussion/community UI, moderation, announcements, social graph                          |
| Administration | Global-admin-only console: searchable user directory, activate/deactivate, role changes (with self-lockout guards), platform-wide course oversight, and a platform audit log                                                                                        | Delegated/scoped administration, bulk user operations                                     |
| Organizations  | Organization creation, owner/admin/member roles, email invitations (hashed, time-limited, status computed at read time), member management, assigning members to existing published courses, per-member progress reporting, an organization-scoped audit log        | Org-owned private course catalogs/authoring, billing/seats, SSO-linked provisioning       |
| Notifications  | In-app notification center (quiz graded, assignment graded, certificate issued) with unread count and mark-read; password-recovery and organization-invitation email when SMTP is configured                                                                        | Push notifications, delivery preferences, delivery tracking, general course announcements |
| Operations     | Health/readiness/dependency probes, protected metrics, structured logs, optional traces, migrations, backups, Kubernetes, release/deploy/rollback workflows                                                                                                         | Verified cloud deployment, provider configuration, queue workers, tested restore/failover |

Historical demo-only learner, assessment, notification, certificate, and admin components were removed and later rebuilt on real, persisted data (see CHANGELOG). The admin console and organization tenancy (invitations, membership, assign-learning, audit logs) were later added on the same real, persisted-data foundation.
